# Tool reference

Every tool is a plain Python script: `python tools/<name>.py --help` (most print their own manual in the first screen of the file, too). They are grouped in the order you use them. Generated by `tools/export_workflow.py` from each tool's own docstring - when this page and a tool disagree, the tool is right.

Run them from the `workflow/` folder. `python foc.py tools` prints this list in the terminal.

## 2. Find things

Search the games for art, protos, tiles, buildings and rooms; build the fragment corpus and the art index.

| Tool | What it does |
|---|---|
| `find_art.py` | List FOC art list entries (index, name) matching regexes. |
| `findart.py` | What art exists for a thing, across every source, with its cost. |
| `find_buildings.py` | Find buildings, in any source's maps, walled in given wall families (e.g. |
| `find_proto.py` | Search FOC's protos by display name or art name. |
| `find_rooms.py` | List the rooms of any source level, so compose_map.py can lift single rooms instead of whole levels. |
| `find_source_item.py` | Search every source game's item names (pro_item.msg) for words, to find something to port with port_item.py. |
| `find_tile.py` | List FOC floor/roof tile ids by name prefix (ids below 4096, the only ones gecko and the engine can address). |
| `open_tiles.py` | List open floor hexes in a hex rectangle of a FOC map: no blocking object, no exit grid within 2 hexes, reachable on foot from the map's start, at least --spacing hexes apart. |
| `stamp_extent.py` | Print the hex footprint of gecko stamps (dx/dy range of their objects), for laying them out with compose_map.py. |
| `corpus.py` | Build a searchable library of human-composed map fragments. |

## 5. Finish the map

Edges, scroll blockers, exits, links, trimming and cleanup, the way Fallout 2 does them.

| Tool | What it does |
|---|---|
| `map_edges.py` | Give FOC's maps Hi-Res Patch edge files (maps/<name>.edg), so the camera stops at the edge of the painted ground and the void beyond is never seen. |
| `map_edge_blockers.py` | Stop the player walking into the black edge of a map. |
| `scroll_ring.py` | Replace a map's scroll-blocker ring with one sized to the map's actual content, so the camera can't be scrolled out past it into undecorated wasteland or the void beyond. |
| `exit_layout.py` | Lay out each FOC map's exits and edge the way Fallout 2 does: Fallout 2's own exit prefabs (tools/exit_templates.json) at the edge box where each road leaves, a row of invisible block hexes along the rest of the box edge, and t... |
| `exit_templates.py` | Copy exit-grid prefabs out of Fallout 2's own maps, object for object, into tools/exit_templates.json, for tools/exit_layout.py to stamp onto FOC's maps. |
| `exit_restyle.py` | Rebuild every exit-grid patch on FOC maps the way Fallout, Fallout 2 and the TCs lay them out. |
| `map_exits_to_edge.py` | Rebuild a map's exit-grid ring at the edge of its painted floor. |
| `map_link.py` | Link two maps with exit grids. |
| `check_links.py` | Check every way into and out of FOC maps. |
| `map_trim.py` | Trim a map to a clean edge: floor cut straight along the tile grid, a tidy exit band just inside it, and a camera ring. |
| `shift_map.py` | Move everything on a map (every elevation) by an even number of hexes, so a town that sits off to one side of the 200x200 grid ends up in the middle, where its edge box (maps/<name>.edg) has painted ground all round. |
| `paint_corners.py` | Paint ground into the void corners that a map's edge box (maps/<name>.edg, tools/map_edges.py) still takes in, the way the originals have floor painted out past their boxes. |
| `strip_blockers.py` | Remove stray invisible blocking hexes from a map. |
| `car_blockers.py` | Fill the footprint of car / caravan-cart scenery with invisible blocking hexes, so the sprite reads as solid instead of something you walk through. |
| `map_vehicle_blockers.py` | Make cars, trucks, wagons and carts solid on a map. |
| `remove_black_frames.py` | Take the black frame pieces (RPU's BLACK002 / BLACK003 scenery, drawn with gecko's Black Edge tool) off FOC's maps. |
| `map_header.py` | Set a FOC map's header script and/or player start, in place. |
| `sync_maps.py` | Copy a map you just edited in gecko back into the authored source tree, so it survives the next deploy.py run. |
| `swap_critters.py` | Turn critters of some protos on a map into another creature, keeping each one where it stands, its facing, its script and its inventory. |

## 6. Borrow from other games

Browse another game in gecko, save stamps, and convert them into your mod's id space; port protos and art; make your own scenery.

| Tool | What it does |
|---|---|
| `build_gecko_browsers.py` | Generate tools/gecko_browse/, one launcher per TC. |
| `port.py` | Pull assets in from another Fallout 2 install and remap them into this project's ID space. |
| `port_bulk.py` | Port every distinct proto of the given types from one or more sources into FOC's own data in one pass, skipping anything whose ART is byte-identical to something FOC's data already has or that an earlier source in this same run... |
| `port_stamp.py` | Convert a gecko stamp saved while browsing another game (via tools/gecko_browse) into FOC's ID space, so it stamps the same thing in the FOC editing profile. |
| `tile_slots.py` | New floor and roof tiles for FOC, in slots of tiles.lst that hold nothing FOC can lose. |
| `repack_art.py` | Move every piece of FOC art that something actually uses below the engine's 4096 art-index cap, swapping unused art up past it. |
| `fix_art_names.py` | Bring every FOC art filename within the engine's 12-char limit. |
| `fonline2_source.py` | Make the FOnline 2 client usable as an asset source, like the TC installs, without repeating anything we already have. |

## 7. Register and play

Allocate ids, assemble the game's lists, register the map on the world map, check cross-references and deploy into the working copy of the game.

| Tool | What it does |
|---|---|
| `ids.py` | The project's ID space. |
| `gen_ids.py` | Turn mod/ids/*.txt into the generated header scripts_src/foc/foc_ids.h. |
| `lists.py` | Assemble the .lst / .gam files the game actually loads. |
| `questlog.py` | Build the Pip-Boy quest log (data\quests.txt) from mod/quests.txt. |
| `worldmap.py` | Register FOC maps with the engine (maps.txt / city.txt / map.msg) and fit worldmap.txt to FOC's West Texas worldmap art. |
| `validate.py` | Check the mod's ID space and cross-references before it ever runs. |
| `deploy.py` | Assemble the mod into the working base install so it can be played. |
| `install-sfall.py` | Install an upstream sfall release into the working base. |
